Post thumbnails

New/Edit Post includes Thumbnail above Related Posts, with a preview, Upload Thumbnail, and Apply Default Placeholder. Uploaded/generated images use the same {{ context.codeblock18 }} upload API and configured storage provider as other media. Posts store only {{ context.codeblock19 }}; image data is never stored in the content entity. Thumbnail keys are saved, duplicated, and revisioned alongside the other content fields. Cancel discards draft changes without deleting assets needed by revisions or other posts.

Every successful video upload/replacement triggers browser-native extraction from that selected {{ context.codeblock20 }}. An object URL feeds a native video element; a small 64-pixel-wide canvas checks luminance at 0.25-second intervals over at most the first five seconds. A frame is usable when at least 2% of its pixels have luminance above 18, allowing small subjects in dark scenes. If none qualifies, the most visible scanned frame is used. The selected frame is encoded as WebP (or the browser's supported fallback), at up to 1280×720 while preserving aspect ratio, then uploaded as an ordinary CMS image asset. Video object URLs are always revoked; extraction never uses {{ context.codeblock21 }}, FFmpeg, or backend video processing.

Every video re-upload replaces the current thumbnail, including a manual override. Unrelated field edits never trigger extraction. Upload Thumbnail can override the result at any time. Local image previews appear before upload finishes, and their object URLs are released on replacement, cancellation, or editor destruction. A generation failure keeps the uploaded video and reports how to choose a manual/default thumbnail.

Defaults are reusable {{ context.codeblock22 }} references, rendered as clean inline SVG illustrations for normal, video, audio, and attachment posts; they do not create duplicate storage objects. Stored image thumbnails use the same permission/publication checks and signed-download policy as other media, including when assets are shared by multiple posts.
