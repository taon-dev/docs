Taon entities

A Taon entity is a TypeScript class that maps to a database table. Taon builds on TypeORM entities. You can also use an entity class as a data transfer object (DTO) when its fields match the API contract. Define a separate DTO when an endpoint accepts or exposes only part of the entity.

Keep entities compatible with SQLite

Shared entity definitions must work with SQLite-backed Taon runtimes, including browser WebSQL mode. Follow the column decorators and mappings already used by the project.

  • Prefer Taon column decorators, such as {{ context.codeblock14 }}, for common field types.
  • Avoid declaring raw {{ context.codeblock15 }} column types in shared entities. For whole numbers, use the project's SQLite-compatible integer column mapping.
  • Avoid database-specific column types such as PostgreSQL {{ context.codeblock16 }}, native enums, and array columns in shared entities. Use a representation supported by each target runtime.
  • Keep column defaults, indexes, and constraints portable. Verify that any database expression used by the entity works on each target.
  • When changing the schema of an existing entity, check the corresponding migration against the same runtimes as the entity.
