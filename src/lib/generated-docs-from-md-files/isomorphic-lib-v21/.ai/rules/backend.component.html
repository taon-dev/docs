Runtime differences

Taon supports these distinct backend targets:

  • Node.js has access to Node.js APIs according to the app's environment and permissions.
  • Cloudflare Workers use an ESM runtime with Worker APIs and do not provide the full Node.js runtime.
  • WebSQL runs backend logic in the browser.
  • Electron uses a main-process backend with privileged Node.js APIs.

Review Transport layer before relying on networking, realtime communication, or platform APIs across targets.
