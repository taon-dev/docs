Runtime and project dependencies

The route tree is Angular/browser code. The active Taon context runs on the backend chosen by the application. Node.js is the normal server target; WebSQL runs backend logic in the browser and does not provide server-side secrets or public webhook reception. Cloudflare Worker deployments need their own bindings and target-compatible database/storage providers. Baseline's abstract context does not select or configure those providers.
