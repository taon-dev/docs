Add Taon Admin to an existing Taon project

This tutorial adds the Baseline backoffice to an existing Taon app and verifies that its modules and permission-gated navigation load.

Prerequisites

  • An existing Taon project with its organization/container dependencies available. Use the project's Taon dependency workflow rather than running {{ context.codeblock0 }} in a Taon container.
  • {{ context.codeblock1 }} and its required packages declared and available through that project dependency workflow.
  • Node.js 22 or later for the current Taon CLI.
  • A Taon application context and Angular router already initialized.
  • Session authorization configured, plus a test account that can be granted the required admin permissions.

If you are starting a project instead, use the CLI commands guide and verify commands against the installed CLI version.
